# AI & Cloud-Enabled Smart E-Commerce Platform for Empowering Rural Artisans

A smart e-commerce web platform that helps rural artisans sell their handmade
products online directly to customers, without depending on middlemen. It uses
AI for product tagging, image-based descriptions, and fair price
recommendations, and stores data on the cloud.

Final-year B.Tech project | Department of Computer Science & Engineering
Aditya College of Engineering (affiliated to JNTUA), Madanapalle

## Problem Statement
- Rural artisans have limited access to customers beyond local markets
- Middlemen reduce their income
- Lack of digital skills makes online selling difficult
- No proper system for fair pricing and demand prediction

## Features
- Artisan registration and product management
- AI image recognition for automatic product tagging and descriptions
- AI-based price recommendations and demand forecasting
- Customer module to browse and buy products
- AI recommendation engine
- Cloud storage for product images, user details, and transaction data
- Analytics dashboard for artisans

## Tech Stack
- Frontend: PHP
- Backend: Python (Flask)
- Database: MySQL
- API: REST API
- AI/ML: Python

## How to Run
1. Install the requirements: pip install flask mysql-connector-python
2. Create the MySQL database and import the .sql file
3. Run the backend: python app.py
4. Open the frontend in your browser
